# MINI CRAFT

[English](README.md) · **Русский**

![Mini Craft — люди против Тумана](docs/logo.jpg)

Стратегия в реальном времени в духе StarCraft в тумане в стиле Silent Hill.
Полевая армия людей против существ из Тумана: стройте базу, добывайте минералы, собирайте армию и уничтожьте врага.

- **Две фракции** — Люди (солдаты, БТР, РСЗО, самолёты, тяжёлый танк) и Туман (искажённые твари, ржавые окровавленные
  постройки, Палач; всё в Тумане регенерирует).
- **Отряды** — командиры ведут до 6 солдат или 4 машин / самолётов и делают их сильнее.
- **Эпохи** — как в Age of Empires: прочнее здания, энергощиты, сильнее юниты.
- **Ракеты** — тактическая, кассетная, напалм и тяжёлая, из ракетной шахты.
- **Туман войны**, броня и типы целей, сохранения, две сложности, русский и английский языки.

## Запуск

1. Установите [Godot 4.3+](https://godotengine.org/download) (обычная версия, не .NET).
2. `git clone https://github.com/r0mik/rts-craft.git`
3. Откройте `project.godot` в Godot и нажмите **F5**.

Отдельная сборка для Windows / Linux: [HOW_TO_RUN.md](HOW_TO_RUN.md).

## Управление

| | |
|---|---|
| Выбор / приказ | ЛКМ, рамка / ПКМ |
| Камера | `WASD`, колесо, `Space` — к базе |
| Атака с продвижением / стоп / держать | `G` / `X` / `H` |
| Группы | `Ctrl+1..9`, `1..9` |
| Отряд (командир + юниты) | `Z` принять, `U` распустить |
| Новая эпоха | Штаб → `E` |
| Быстрое сохранение / загрузка | `F5` / `F9` |
| Пауза, настройки | `Esc` |

Все команды есть и на кнопках внизу справа, с подсказками. Баланс — в `scripts/defs.gd`.
